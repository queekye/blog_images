# 旧博客图片档案

该仓库冻结保存旧文章使用的图片路径，当前不新增内容。现有 `img/` URL 保持可访问，避免旧文章引用失效。

## 图片来源和许可

本仓库不提供覆盖所有图片的开源许可。历史文件没有足够的逐图原始链接、作者及授权记录；公开可访问不表示已确认可以再分发、用于训练或改用其他许可。Typora 图标文件名也不能作为许可证据。使用第三方图片前，应另行核实权利人的适用条件。

逐图路径及原始 Git blob 见 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)。不将这些图片套用 MIT 或其他源码许可证。

## 接手和后续处理

没有安装环境、程序入口或额外资源下载要求；这是静态图片档案。维护旧文章时，应先搜文章源码中的 `queekye/blog_images`、`raw.githubusercontent.com` 引用，再决定是否替换图片或迁移地址。未完成外链核对前保留图片路径。

后续逐图补原始来源、作者和授权证据；无法确认权限的图可以自行重绘或换成已授权素材，再同步更新文章。是否继续公开应以这份来源核对为依据。归档后需要修改时先解除归档；不要把归档状态当作许可核验完成。
